### Question 2
If a script includes an Update function and the script is attached to an object within the current active scene, that script will constantly call its Update function while it continues to exist within the scene. 

### Question 3
In the KickWeapon script, the script repeatedly checks every frame using the Update method if the time on the timer has reached 0; if it has, the script deactivates the GameObject it is attached to. In the TimerText script, the Update method checks every frame whether or not the timer is finished, and activates the game over screen when it has.
